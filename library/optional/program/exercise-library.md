# Exercise Library & Substitutions

> Pre-approved swaps. The purpose is to remove the decision at the moment it's needed:
> if the rack is taken or the shoulder is cranky, there is already an answer here and
> the session doesn't get skipped.

| Pattern | Primary | Sub A (equipment) | Sub B (joint-friendly) |
|---|---|---|---|
| Squat | Goblet / KB front squat (controlled ROM) | Split squat | Leg press / box squat to comfortable depth |
| Hinge | Single-arm KB swing | Trap-bar or RDL from controlled range | Hip thrust / back extension |
| Horizontal push | Push-up (weighted/deficit to progress) | DB/KB floor or bench press | Incline push-up |
| Horizontal pull | 1-arm DB/KB row | Inverted row | Chest-supported row |
| Vertical push | KB/DB overhead press | Landmine press | Half-kneeling press |
| Vertical pull | Pull-up / assisted | Lat pulldown | Band-assisted pulldown |
| Lunge / single-leg | Reverse lunge | Step-up (knee-safe height) | Split squat (L-knee: pain-free ROM) |
| Hip extension | Hip thrust | KB swing | Glute bridge / back extension |
| Core / anti-rotation | Pallof press | Suitcase carry | Dead bug / bird dog (also back prehab) |

## Rules
- A substitution keeps the pattern and the rep range. It is not a downgrade and does not
  need approval.
- Never substitute out of a pattern two sessions in a row without logging why in the
  daily log — that's a signal, not a preference.

## Travel / no-equipment fallback
> The minimum viable session. Never zero. (Travel is this athlete's #1 historical
> streak-ender — this block is load-bearing, not an afterthought. First live test: Portugal, Aug 31.)
- Push-ups, burpees, bodyweight squats/split squats (knee-safe ROM), jump rope (knee
  permitting), plus the low-back rehab routine + left-knee rehab block. Bands if packed.

## Contraindicated for this athlete
> From injury history (`athlete/injury-history.md`). Read that file for the full picture.
- **Heavy barbell back squat** — avoid by default (L4 rupture / L3 bulge, 2019). Sub: goblet/KB front squat, split squat, leg press in controlled ROM.
- **Heavy conventional deadlift** — avoid by default. Sub: single-arm KB swing/clean, trap-bar/RDL from controlled range, hip thrust.
- **Running (distance)** — modify / earn back; provokes L3–L4 soreness. Sub: seated bike, ruck, incline walk.
- **Standing Peloton climbs while left knee is symptomatic** — modify: seat the climb, cap standing time, drop resistance. Titrate bike volume to the knee.
- **Medial/valgus loading of the left knee** (e.g., BJJ butterfly hooks) while symptomatic — modify where controllable; not fully controllable in live rolls.
- **Jefferson curls & high-rep crunches** — SUBSTITUTE NOW (not "monitor"). Loaded/repeated
  lumbar flexion into the 2019-injured segment = the disc-herniation mechanism; tolerance
  drops in a deficit. Replace with anti-flexion/anti-rotation core: plank, side plank, dead
  bug, bird dog, Pallof press, suitcase carry. Same trunk stimulus, no flexion load.
- **Nerve rule:** any radiating leg pain / numbness / tingling / weakness → stop, refer out same day (not a substitution decision).
