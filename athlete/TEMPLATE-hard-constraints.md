# Hard constraints

> **Read before naming any food. Every time. Not delegated to a specialist** —
> CLAUDE.md §5.1.
>
> This file holds **only** things where exposure is a **medical event**, not a setback. A
> preference belongs in `values.md`; a dislike belongs in `profile.md`. Mixing them
> weakens the file, because a list that is mostly preferences stops being read as a floor.

## Allergies

_For each: the substance, the reaction, the severity, whether trace amounts and
cross-contamination matter, and whether an epinephrine auto-injector is carried._

_If intake found none, write "None on record" with the date — a measured absence is a
finding, not an unasked question._
